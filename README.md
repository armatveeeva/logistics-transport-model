# Адаптивная модель международной транспортной системы грузоперевозок

[![Python Version](https://img.shields.io/badge/python-3.11%2B-blue)](https://www.python.org/)

[![SQLAlchemy](https://img.shields.io/badge/ORM-SQLAlchemy-red)](https://www.sqlalchemy.org/)
[![Data](https://img.shields.io/badge/data-Pandas-orange)](https://pandas.pydata.org/)

Репозиторий содержит информационное ядро (data layer) адаптивной модели международной транспортной системы грузоперевозок — реляционную базу данных и скрипты для её наполнения, верификации и экспорта.

Данный этап работы реализует концептуально-структурную основу модели: формализованную схему из 9 связанных сущностей (бассейны, порты, операторы, контейнерные линии, грузы, инциденты, риски) и набор верифицированных параметров 19 ключевых морских портов Российской Федерации, распределённых по 5 бассейнам.

## Описание предметной области

Модель охватывает 5 ключевых морских бассейнов Российской Федерации (Дальневосточный, Балтийский, Азово-Черноморский, Арктический, Каспийский) и 19 стратегически важных морских портов. Система спроектирована для систематизации реальных параметров транспортных объектов, что обеспечивает основу для:
- Динамического обновления весов ребер ориентированного графа транспортной сети.
- Проведения сценарного моделирования устойчивости логистических коридоров.
- Обучения и калибровки прогностических алгоритмов машинного обучения (Random Forest, XGBoost) для оценки рисков.

## Структура базы данных

Информационное ядро системы построено на реляционной модели и включает 9 связанных таблиц:

| Таблица | Описание | Примерный объем |
|---------|----------|-----------------|
| `basin` | Морские бассейны, объединяющие порты по географическому признаку | 5 записей |
| `port` | Морские порты с инфраструктурными характеристиками | 19 записей |
| `operator` | Реестр операторов терминалов и их юридические данные | ~175 записей |
| `service_type` | Классификатор типов услуг, предоставляемых операторами | ~57 записей |
| `container_line` | Контейнерные линии и их агенты в портах | ~41 запись |
| `container_turnover` | Динамические показатели контейнерооборота (временные ряды) | ~120+ записей |
| `cargo` | Номенклатура грузов с указанием типа и стоимости | 15 записей |
| `incident` | Реестр зафиксированных инцидентов и происшествий | 80+ записей |
| `risk` | Оценка рисков, сопряженных с конкретными инцидентами | 80+ записей |

## Технологический стек

- **Язык:** Python 3.11+
- **ORM:** SQLAlchemy 2.0
- **База данных:** SQLite (по умолчанию для локальной разработки), PostgreSQL (для продакшена)
- **Обработка данных:** Pandas, OpenPyXL
- **Управление конфигурацией:** Pydantic Settings, python-dotenv

## Статус проекта

На текущем этапе репозиторий содержит:
- схему реляционной базы данных (SQLAlchemy ORM);
- верифицированный набор данных по 19 портам, ~175 операторам, 41 контейнерной линии, 80 инцидентам и сопряжённым рискам;
- скрипты инициализации, загрузки и экспорта данных.

Следующие этапы развития:
- аналитический модуль (расчёт весов рёбер графа транспортной сети);
- прогностический модуль (Random Forest, XGBoost для оценки рисков);
- веб-платформа с интерактивной визуализацией и сценарным моделированием.
